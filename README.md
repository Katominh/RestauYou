# RestauYou 
## A Restaurant Management Application

RestauYou is an Android-based application designed to streamline and simplify restaurant operations for both customers and restaurant owners. The app aims to improve organization, communication, and the overall dining experience.

---

## 🚀 Key Features

### **Customer-Side**
* **Registration & Login**: Offers a simple login for existing users and a signup option for new accounts.
* **Guest Access**: Includes a "Continue as guest" option to explore features without an account.
*   **Digital Menu**: Displays food items in a card layout with pictures, names, prices, and descriptions.
*   **Table Reservation**: A built-in system allowing users to book tables by providing details and selecting time slots.
*   **Settings & Profile**: Users can manage personal details, delivery addresses, and notification preferences.
*   **Secure Payments**: Supports secure payment methods to speed up the checkout process.

### **Admin-Side**
*   **Menu Management**: Admins can add, edit, or delete dishes to keep the menu current.
*   **Order Tracking**: Provides real-time tracking of orders with status indicators like Pending, Preparing, Ready, and Delivered.
*   **Staff Scheduling**: Allows admins to manage and view staff shifts on a weekly basis.
*   **Customization**: Admins can update restaurant information and configure notification alerts.
*   **Real-Time Notifications**: Features instant alerts and sound cues for new orders and status updates.

---

## 🛠️ Technology Stack
*   **Development Environment**: Android Studio
*   **Languages**: Java and XML
*   **Backend**: Firebase (Authentication, Real-time Database, and Storage)
*   **UI Components**: Material Design (MaterialButtons, ShapeableImageViews)
*   **Data Management**: ViewModel for synchronization and Google Gson with Shared Preferences

---

## 📖 Instructions for Use

### **For Customers**
1.   **Signup**: New users must create an account with a username and a password of at least 6 characters
2.   **Browsing**: View the menu to add items to your cart and proceed to checkout
3.   **Reservations**: Enter your name, phone, and date to select a reservation time

### **For Admins**
1.   **Access**: Log in using dedicated administrative credentials
2.   **Dashboard**: Navigate between Menu, Order, and Schedule management sections to oversee operations
